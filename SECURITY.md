# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through a public GitHub issue.

For sensitive security reports, contact the repository owner through the contact information available on the owner's GitHub profile.

## Scope

Security reports may include:

- exposed credentials or secrets
- unsafe file handling
- unintended arbitrary file access
- API vulnerabilities
- dependency vulnerabilities
- insecure deployment configuration

Please avoid including private data, credentials, or exploitable proof-of-concept details in public issues.
